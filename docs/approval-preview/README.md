# Проверка утверждения и экспорта

2 ноября 2026 года. Синтетический проект «Пример · Студия Север». Обычный локальный API 0.5.0, PostgreSQL и настоящий валидатор. Ключ OpenAI исключён из окружения проверочного процесса; живых обращений к модели на этом этапе не было.

## Что проверено

- Ручная R1 меняет s05 на Дениса и превышает его личный лимит. Сначала версия имеет статус «не проверено», затем получает 6/7 и не допускается к утверждению.
- R2 исправляет s08 на Олега. Повторная проверка 7/7, две перестановки, 14/14 смен, 112 часов, оплата 31 040 RUB, разница к исходнику −640 RUB.
- Отметка просмотра назначений разрешает утверждение только проверенной сохранённой версии. Оптимальность ручной версии не заявляется.
- Подготовлены CSV и XLSX, скачаны через реальные кнопки интерфейса. SHA-256 и размер полученных файлов сверены с квитанциями.
- После полного выключения PostgreSQL, API и worker и нового запуска сохранились R1/R2, утверждение, оба файла и прежние SourceVersion V3 / TaskSpec V9. Оригинальный XLSX остался с прежним SHA.
- После перезапуска оба выданных файла прочитаны настоящим импортёром и независимо проверены: 14 смен, 112 часов, 31 040 RUB, pass.

Утверждение: a6a084df-3e0a-4652-bbd7-d66e94448a62. SourceVersion ef5e88b8-d518-4254-a594-7113d45229d0, TaskSpec 66b26854-cee0-461c-8e4c-c965b2b19d6a. Hash исходника c72de2f7a6c04145db133b1f5f66031d9c3a50402369f4ae3388cd8a450969d4.
