Анимации и фаза цифрового дождя не детерминированы. Сравнение выполняется по геометрии, типографике, палитре, графике и видимым состояниям, с учётом ожидаемой новой ссылки WORKSPACE.

Сравнение первого экрана с текущей версией при одинаковом размере 1440×900: JPEG-область логотипа совпала пиксельно; средняя абсолютная разница RGB ниже навигации — 0.023 из 255. Это проверка первого экрана, а не утверждение о пиксельном совпадении всех анимированных состояний. Текущий кадр — `../workspace-preview/home-desktop.jpg`.
