# Проверка текстовых черновиков

2 ноября 2026 года. Данные синтетические. Живой API при этих проверках не использовался.

На снимках с окончанием -test ответ модели имитируется отдельным контрольным адаптером; это обозначено в самой странице. Импорт, PostgreSQL, версии, подтверждение, очередь, OR-Tools CP-SAT и валидатор работают по настоящему коду приложения.

## Контрольный проект

Отдельная временная база и временные файлы. Запрос: «Анна не выйдет в среду, 4 ноября. Сравни варианты.» Черновик сопоставляет отсутствие с интервалами s05 и s06; подтверждение четырёх групп создаёт TaskSpec V2, исходник остаётся V1.

Исходные CSV из docs/examples/absence: 10 сотрудников, 14 смен, 112 часов, оплата 31 200 RUB. Настоящий расчёт выдаёт одну замену Анны на Софию (+160 RUB, 31 360 RUB за неделю) и вариант с двумя заменами (−480 RUB, 30 720 RUB). Независимые проверки 7/7, покрытие 14/14.

Проверено в UI: согласие связано с точным текстом и версиями; три отметки не разрешают подтверждение; четыре разрешают; изменённый текст запрещает подтверждение старого результата. После перезагрузки сохраняются новые условия, происхождение, расчёт и история; записи упорядочены по времени. Тестовые задания не могут попасть в живой адаптер без явной инъекции.

## Прежний сохранённый проект и лендинг

- [existing-project-no-key.png](./existing-project-no-key.png) — обычный API 0.4.0 запущен с ключом, исключённым только из окружения проверочного процесса. Контрольный адаптер отсутствует, текстовый разбор недоступен. Старые SourceVersion V3 и TaskSpec V9 открылись; новый schedule-cpsat/2 расчёт дал прежние суммы 31 680 RUB или 31 040 RUB, 7/7 проверок и 112 часов.
- [home-preserved.png](./home-preserved.png) — возврат из workspace восстановил язык en и пять секций лендинга. Исходные шрифты, палитра, графика и переходы сохранены.

Разница сумм между проектами объясняется ставкой Анны в V3 прежнего проекта. Контрольный проект использует первоначальные CSV.

В свежих production-вкладках ошибок и предупреждений консоли не было. Размеры проверены по DOM и фактическим PNG; перед финальными снимками панелей проверена непрозрачность 1.

Итог автоматических проверок: 97 backend-тестов с настоящим PostgreSQL, 31 тест TypeScript, сборка и соответствие API-типов. В backend есть одно предупреждение стороннего TestClient о будущей смене HTTP-клиента.

Проверочные базы и временные файлы удалены, обычный сохранённый проект оставлен с прежними версиями и новым проверочным Run. API, worker и серверы интерфейса после проверки остановлены. Воспроизведение контрольного режима: npm run ai:preview и npm run dev в разных терминалах; подробности — [INTENT_STAGE.md](../INTENT_STAGE.md).
